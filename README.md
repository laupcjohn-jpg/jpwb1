# 日语学习 · 单词与测验

一个纯前端的日语单词学习网站，无需安装任何环境，双击打开即可使用。

## 如何运行

- **最简单**：双击 `index.html`，用浏览器打开即可（推荐 Chrome / Edge / Firefox）。
- 数据保存在浏览器本地（`localStorage`），换浏览器或清除浏览器数据会导致数据丢失，**请定期导出备份**。
- 需要手机和电脑共用一份词库时，用「云同步」（见下文）；只在本地用时不需要任何后端。

## 功能

### 1. 添加单词 / 语句

页面顶部可切换两种录入模式：**📝 单词** 和 **💬 语句**。

#### 单词模式

录入单词的这几项内容（只有假名、词性、意思是必填）：

| 字段 | 必填 | 说明 |
|------|------|------|
| 汉字 | 否 | 如「食べる」；纯假名词（如「ありがとう」）可留空 |
| 假名 | 是 | 读音，如「たべる」 |
| 词性 | 是 | 从你设置的分类中下拉选择；用于归类查看与测验干扰项抽取 |
| 自他 | 否 | 自动词 / 他动词 / 自他动词；**只有动词需要填**，留空显示「—」。只在单词库的动词类分类里显示 |
| 意思 | 是 | 中文释义，如「吃」 |
| 例句 | 否 | 如「毎朝パンを食べる。」；可留空，显示在单词库对应词条下方 |

#### 语句模式（只输入句子）

不想拆成单词、只想整句收藏时用这个模式，字段只有两个：

| 字段 | 必填 | 说明 |
|------|------|------|
| 句子 | 是 | 如「毎朝パンを食べる。」 |
| 中文翻译 | 否 | 如「每天早上吃面包。」 |

- 保存后自动归到单词库的「语句」分类下，可以像单词一样编辑、删除。
- 句子是多行输入框，回车是换行；保存请点按钮或按 **Ctrl / Cmd + Enter**。
- **语句不参与测验**，也不记出现次数与正确率。

### 2. 单词库（按分类查看）

- 按分类分组展示：单词按词性分组，语句集中在「语句」分类下，分类页按分类表的顺序排列。
- 每个单词显示：汉字、假名、意思、**出现次数**、**答对次数**、**正确率**；填过例句的词会在下方多显示一行例句。
- **动词类分类**（分类名里带「动词」，也就是一类/二类/三类动词）会多一列「自他」：
  自动词 / 他动词 / 自他动词各有一种颜色的小标签，没填的显示「—」。其它分类不显示这一列。
- 语句只显示整句与中文翻译。
- 支持编辑、删除。

#### 检索（跳到那一行）

单词库顶部的检索框输入关键词（**汉字 / 假名 / 意思 / 例句 / 自他**都能匹配），**按回车**就会跳到第一个
匹配条目所在的分类，滚动到那一行并闪烁标出，命中的关键词同时高亮：

- 再按一次回车 → 跳到下一个匹配；跳完最后一个会回到第一个，循环往复。
- 右侧显示「第 2 / 5 个匹配」，一目了然。
- 没匹配到会显示「未找到」；**清空输入框**即退出检索、恢复完整列表。

#### 分类管理

页面顶部的「分类管理」面板可以自定义词性分类（默认采用《标准日本语》体系：一类/二类/三类动词、一类/二类形容词、名词、语句）：

- **添加分类** —— 输入名称后点「添加分类」或按回车。
- **「语句」分类**是语句专用的，录入第一条语句时若不存在会自动创建；单词请选别的分类。
- **重命名**（✎）—— 改完按回车或点 ✓ 保存；该分类下的**所有单词会同步改名**，不会掉队。
- **删除**（🗑）—— 只允许删除空分类；若分类下还有单词，会提示先处理这些单词。系统至少保留一个分类。

如果单词的词性不在当前分类表里（例如导入了外部数据），该分组会标注「未登记分类」并排在最后，方便你把它加进分类表。

### 3. 测验练习

页面顶部可以切换两种练习模式：

- **📖 读音 + 意思** —— 原来的题型（下面这一节）
- **✍️ AI 造句** —— 自己写日语句子交给 AI 批改（见「[AI 造句判题](#ai-造句判题可选)」）

#### 📖 读音 + 意思

- 每次练习 10 个单词（词库不足 10 个时使用全部）。
- **限定分类（可多选）**：开始页可以只勾选某几个分类出题（例如「一类动词 + 二类动词」），
  每个分类旁显示词数，下面显示「本次可抽 N 个单词」。勾选会被记住；
  一个都不勾时会提示不能开始。这就是「指定分类练习」。
- **语句不参与测验**：既不出题，也不会被抽来当「意思四选一」的干扰项；开始页的词库统计同样只算单词。
- 每个单词两问，**两问都答对才计 1 分，任意一问答错不计分**：
  1. **看汉字写假名**：给出汉字，输入其假名读音；纯假名词（无汉字）跳过此题。
  2. **意思四选一**：从同词性单词中抽取意思（最多 4 个选项，词库不足时选项更少），选出正确的一个。
- 假名判分时**平假名 / 片假名视为等价**（如输入「タベル」也算对「たべる」）。
- 每题**答完后**，反馈区会显示该词的例句（填过例句的词才有）。答题过程中故意不显示——
  例句常常直接点明意思，答题时就给出来会剧透「意思四选一」那题。

### 4. 记录与掌握机制
- 每个单词记录「出现次数」和「答对次数」，在单词库中查看。
- **当某单词出现次数 > 5 且正确率 > 80% 时，其被抽中概率会降低**（加权抽取），让你把精力集中在没掌握的单词上。

## 云同步（手机与电脑共用一份词库）

侧边栏底部的「☁️ 云同步」，填一个**同步码**并点「连接」即可。手机和电脑填
**同一个同步码**就共享同一份词库；填不同同步码则是完全隔离的两份数据。

- 打开页面会自动拉取一次云端数据；之后每次增删改单词、做完测验，会在约 2 秒后自动上传。
- 也可以随时点「立即同步」手动触发。
- 断网或服务端异常时，**本地数据不会丢**，状态栏会提示失败，恢复后重试即可。

同步规则（两端都改了同一个词时的处理）：

| 情况 | 结果 |
|------|------|
| 一个词只在一端新增 | 另一端会拿到 |
| 一个词只在一端删除 | 另一端也会删掉（删除会被记住并传播） |
| 两端都改了同一个词 | 修改时间较晚的一方胜出；时间完全相同则按内容固定裁决，保证两端结果一致 |
| 两端各自新增分类 | 取并集 |

> 同步码就是唯一凭据，没有账号体系，**请选一个足够私密、别人猜不到的码**。
> 知道同步码的人就能读写这份数据。

### 部署云同步需要做的两件事

云同步依赖 `functions/` 目录（Cloudflare Pages Functions）和一个 D1 数据库。
**只用本地功能（不填同步码）时，这两步可以完全不做。**

1. **建 D1 数据库**：Cloudflare 控制台 → Workers & Pages → **D1** → Create database，
   名字随意（例如 `jpwb`）。
2. **绑定到 Pages 项目**：进入你的 Pages 项目 → Settings → **Functions** →
   D1 database bindings → Add binding：
   - Variable name 必须填 **`DB`**（代码里写死的，不能改名）
   - D1 database 选刚建的那个

绑定后重新部署一次即可。代码会自己建表，不需要手动跑 SQL。

若忘记绑定，点「立即同步」会提示「服务端未绑定数据库」。

## AI 造句判题（可选）

「测验练习」里的 **✍️ AI 造句** 模式：给出中文意思和目标词，你自己写一句日语，
交给 AI 老师批改——指出助词、时态、活用、自他动词的问题，给出更自然的说法和一句中文点评。

- 判定分三档：✅ 正确 / ⚠️ 基本正确 / ❌ 需要修改，并附一个 0–100 的分数。
- 结果**单独统计**（单词库里显示「✍️ 造句 通过 / 次数」），**不会**混进读音题 / 意思题的
  正确率和「已掌握」算法——AI 判定是模糊的，不该污染那套掌握度。
  每次开始造句前有一个勾选框，可以决定这一轮要不要记录（选择会记住）。
- **密钥不进浏览器**：模型调用全在服务端（`functions/api/ai.js`），浏览器只带着同步码请求，
  所以页面公开挂出去也不会泄露 AI 凭据。
- 答题时**故意不显示参考例句**，批改完才给出来，免得直接抄。
- 没部署、没绑定 AI、断网、额度用完、AI 没按格式回答……都会给中文提示；
  提交失败时你写的句子会保留在输入框里，可以直接重试，不影响其它功能。

### 启用步骤

1. **部署到 Cloudflare Pages**：把仓库连上去即可（静态页面 + `functions/` 会一起部署）。
   本机双击 `index.html` 打开时没有后端，AI 面板会显示「本机文件打开：AI 不可用」。
2. **绑定 Workers AI**：Pages 项目 → Settings → **Functions** → **Workers AI bindings** →
   Add binding，Variable name 必须填 **`AI`**。
   （不想用绑定也可以走 REST：改设 `CF_ACCOUNT_ID` + `CF_API_TOKEN` 两个环境变量。）
3. **有一个能用的同步码**：AI 用**同步码**当访问凭证——只有 D1 里已经存在数据的同步码才放行，
   所以在侧边栏连过一次同步码就能用，不需要额外配置。
   也可以设环境变量 `AI_ACCESS_CODE`，改用一个独立的访问码。

| 环境变量 | 作用 |
|---|---|
| `AI`（绑定） | Workers AI 绑定，变量名必须是 `AI` |
| `CF_ACCOUNT_ID` + `CF_API_TOKEN` | 不想用绑定时走 REST API |
| `AI_MODEL` | 指定模型，例如 `@cf/meta/llama-3.3-70b-instruct-fp8-fast`；服务端设置优先于页面里选的 |
| `AI_ACCESS_CODE` | 用独立访问码代替「同步码」鉴权 |

### 模型怎么选（实测数据）

同一个「自他动词用错」的句子（目标词 開く〈あく・自动词〉，学生写「私はドアを開く」），各模型实测：

| 模型 | 耗时 | 判题质量 |
|---|---|---|
| `@cf/meta/llama-3.3-70b-instruct-fp8-fast` | **1.8s** | ✅ 默认；指出自他动词用错，改成「私はドアを開ける」 |
| `@cf/mistralai/mistral-small-3.1-24b-instruct` | 2.0s | ✅ 也判对了 |
| `@cf/qwen/qwen3-30b-a3b-fp8` | 2.5s | ✅ 病因对，但偶尔用日语回答 |
| `@cf/meta/llama-3.1-8b-instruct-fp8` | 3.7s | ⚠️ 会看错病因 |
| `@cf/meta/llama-3.2-3b-instruct` | 1.0s | ⚠️ 最快但质量一般 |
| `@cf/google/gemma-4-26b-a4b-it` | 13.7s | ✅ 但慢 |
| `@cf/zai-org/glm-4.7-flash` | 24～77s | ❌ 思考过程吃光输出，经常空回答 →「无法判定」 |

侧边栏可以直接换模型，也可以手填任意 Workers AI 的模型 ID（不消耗额度的是「检测」按钮）。

### 又慢又「无法判定」是怎么修的

- 默认模型换成实测最快的那个；`max_tokens` 从 900 压到 **450**（判题只要一小段 JSON，输出减半就快一倍）。
- 带思考模式的模型（qwen3 / qwq / glm-4.7 / glm-5）会显式关掉 thinking
  （`chat_template_kwargs.enable_thinking=false`）；模型不认这个参数就自动去掉重试。
- 模型返回空内容 / 不是 JSON / 给不出明确判定 → **自动用「只输出 JSON」的短提示再问一次**。
- 解析器认得中文判定词（正确 / 基本正确 / 需要修改）和「78分」这类写法，不再因为措辞不同判成「无法判定」。
- 相同句子 + 相同模型的结果会**本地缓存**：重试、复练是瞬时的，不再花额度。
- 批改页底部会显示「模型 · AI 用时 · 总共用时 · 是否重试」，慢在哪一眼可见。

### 看到 AI 的思路

- 判定区显示 **🧠 批改思路**：模型自己说它检查了什么、为什么这么判。
- 下面是可展开的「**查看 AI 原始输出 / 思考过程**」：模型若返回了思考内容（reasoning）会一起显示，
  原始输出始终保留；**判定不明时这个区块自动展开**，不用猜。
- 说明：真正的思维链模型（qwq-32b、deepseek-r1 这类）会明显更慢（常见 30 秒以上），
  和「要快」冲突，所以默认用快模型 + 展示它的简要思路；想要完整思维链可以在侧边栏手填那些模型 ID 试。

> 免费额度：Workers 免费计划每天 10,000 Neurons。注意部分大模型（如 Kimi K2.6、GLM-5.2）
> [已改为需要 Workers 付费计划](https://developers.cloudflare.com/changelog/post/2026-07-28-models-require-workers-paid/)，
> 侧边栏和开始页都会显示当前模型是否可用，随时可以换一个。

## 数据备份

- 侧边栏「导出备份」：下载当前词库为 JSON 文件。
- 侧边栏「导入备份」：合并导入 JSON 文件（相同单词会跳过，不会丢失现有数据）。
- 云同步**不能替代备份**：同步码丢失或云端数据被误删时，仍以本地导出的 JSON 为准。

## 文件结构

```
index.html      页面结构
styles.css      样式
js/store.js     数据存储层（localStorage 读写、导入导出、变更通知、删除墓碑）
js/quiz.js      测验逻辑（加权抽取、出题、判分、假名归一化）
js/sync.js      多端同步（拉取 → 合并 → 上传，防抖自动同步）
js/ai.js        AI 判题前端（模型选择、可用性探测、批改请求、错误提示）
js/app.js       界面逻辑（视图路由、表单、分类页、测验流程、造句练习、同步与 AI 面板）
functions/api/data/[key].js   同步后端（Cloudflare Pages Function + D1）
functions/api/ai.js           AI 判题代理（Cloudflare Pages Function + Workers AI）
```

## 可调参数

在 `js/quiz.js` 顶部：

- `QUIZ_SIZE` —— 每次练习的单词数（默认 10）。
- `MASTER_APPEARED` —— 掌握判定的出现次数阈值（默认 5，严格大于）。
- `MASTER_RATE` —— 掌握判定的正确率阈值（默认 0.8，严格大于）。
- `MASTER_WEIGHT` —— 已掌握单词的抽取权重（默认 0.2，越小出现概率越低）。
- `SENTENCE_SIZE` —— 每次 AI 造句练习的题数（默认 5）。

在 `js/ai.js` 顶部：

- `DEFAULT_MODEL` / `MODELS` —— 默认模型，以及侧边栏下拉里的候选模型。
- `TIMEOUT_MS` —— 单次批改的超时时间（默认 45 秒）。

在 `js/store.js` 顶部：

- `DEFAULT_CATS` —— 首次使用时创建的默认分类（改动仅对全新用户生效，已有数据请用界面上的「分类管理」调整）。
