# 日语学习 · 单词与测验

一个纯前端的日语单词学习网站，无需安装任何环境，双击打开即可使用。

## 如何运行

- **最简单**：双击 `index.html`，用浏览器打开即可（推荐 Chrome / Edge / Firefox）。
- 数据保存在浏览器本地（`localStorage`），换浏览器或清除浏览器数据会导致数据丢失，**请定期导出备份**。

## 功能

### 1. 添加单词
录入单词的四项内容：

| 字段 | 必填 | 说明 |
|------|------|------|
| 汉字 | 否 | 如「食べる」；纯假名词（如「ありがとう」）可留空 |
| 假名 | 是 | 读音，如「たべる」 |
| 词性 | 是 | 从你设置的分类中下拉选择；用于归类查看与测验干扰项抽取 |
| 例句 | 否 | 如「毎朝パンを食べる。」；可留空，显示在单词库对应词条下方 |
| 意思 | 是 | 中文释义，如「吃」 |

### 2. 单词库（按词性分类查看）

- 按词性分组展示所有单词，分类页按分类表的顺序排列。
- 每个单词显示：汉字、假名、意思、**出现次数**、**答对次数**、**正确率**；填过例句的词会在下方多显示一行例句。
- 支持编辑、删除单词。

#### 分类管理

页面顶部的「分类管理」面板可以自定义词性分类（默认采用《标准日本语》体系：一类/二类/三类动词、一类/二类形容词、名词）：

- **添加分类** —— 输入名称后点「添加分类」或按回车。
- **重命名**（✎）—— 改完按回车或点 ✓ 保存；该分类下的**所有单词会同步改名**，不会掉队。
- **删除**（🗑）—— 只允许删除空分类；若分类下还有单词，会提示先处理这些单词。系统至少保留一个分类。

如果单词的词性不在当前分类表里（例如导入了外部数据），该分组会标注「未登记分类」并排在最后，方便你把它加进分类表。

### 3. 测验练习
- 每次练习 10 个单词（词库不足 10 个时使用全部）。
- 每个单词两问，**两问都答对才计 1 分，任意一问答错不计分**：
  1. **看汉字写假名**：给出汉字，输入其假名读音；纯假名词（无汉字）跳过此题。
  2. **意思四选一**：从同词性单词中抽取意思（最多 4 个选项，词库不足时选项更少），选出正确的一个。
- 假名判分时**平假名 / 片假名视为等价**（如输入「タベル」也算对「たべる」）。

### 4. 记录与掌握机制
- 每个单词记录「出现次数」和「答对次数」，在单词库中查看。
- **当某单词出现次数 > 5 且正确率 > 80% 时，其被抽中概率会降低**（加权抽取），让你把精力集中在没掌握的单词上。

## 数据备份

- 侧边栏「导出备份」：下载当前词库为 JSON 文件。
- 侧边栏「导入备份」：合并导入 JSON 文件（相同单词会跳过，不会丢失现有数据）。

## 文件结构

```
index.html      页面结构
styles.css      样式
js/store.js     数据存储层（localStorage 读写、导入导出）
js/quiz.js      测验逻辑（加权抽取、出题、判分、假名归一化）
js/app.js       界面逻辑（视图路由、表单、分类页、测验流程）
```

## 可调参数

在 `js/quiz.js` 顶部：

- `QUIZ_SIZE` —— 每次练习的单词数（默认 10）。
- `MASTER_APPEARED` —— 掌握判定的出现次数阈值（默认 5，严格大于）。
- `MASTER_RATE` —— 掌握判定的正确率阈值（默认 0.8，严格大于）。
- `MASTER_WEIGHT` —— 已掌握单词的抽取权重（默认 0.2，越小出现概率越低）。

在 `js/store.js` 顶部：

- `DEFAULT_CATS` —— 首次使用时创建的默认分类（改动仅对全新用户生效，已有数据请用界面上的「分类管理」调整）。
